How It Works

1

Fetch Live Data

Enter any ticker. We instantly pull 2 years of daily OHLCV data from Yahoo Finance.

2

Train the Model

We scale the features and train a Random Forest classifier exclusively on the first 80% of data.

3

Predict Tomorrow

We evaluate accuracy on the remaining 20% test set, then run the live model on today's closing metrics to predict tomorrow's direction.
